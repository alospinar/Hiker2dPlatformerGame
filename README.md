# Hiker 2D Platformer Game

Juego de plataformas 2D desarrollado con Unity. El jugador controla a un
personaje a través de tres niveles con enemigos, monedas, trampas, escaleras y
hongos que rebotan.

Este proyecto fue creado como práctica para profundizar en C# y Unity, con
énfasis en:

- Tilemap System.
- Animaciones y Animation State.
- Coroutines.
- Patron de diseño, incluido Singleton.
- Programación orientada a objetos y desarrollo de sistemas de juego en C#.

## Cómo abrir el proyecto

1. Instala la versión `6000.3.24f1` de Unity.
2. Clona este repositorio.
3. Abre la carpeta del proyecto desde Unity Hub.
4. Abre cualquiera de las escenas disponibles en `Assets/Scenes/`.
5. Ejecuta el juego con el botón **Play** del editor.

Las escenas incluidas en la configuración de compilación son:

- `Assets/Scenes/Level 1.unity`
- `Assets/Scenes/Level 2.unity`
- `Assets/Scenes/Level 3.unity`

# Hiker 2D Platformer Game — English

A 2D platform game developed with Unity. The player controls a character
through three levels containing enemies, coins, traps, ladders, and bouncing
mushrooms.

This project was created to deepen my knowledge of C# and Unity, with a focus
on:

- Tilemap System.
- Animations and Animation State.
- Coroutines.
- Design patterns, including Singleton.
- Object-oriented programming and game-system development in C#.
